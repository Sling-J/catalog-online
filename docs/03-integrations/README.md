# 03-integrations: интеграции с учётными системами

Вне MVP: в MVP данные приходят импортом Excel/CSV (FR-A3). Раздел начнётся, когда появится спрос на интеграцию. Оценка рисков — [../00-vision/idea-evaluation.md](../00-vision/idea-evaluation.md), вопросы — [../open-questions.md](../open-questions.md) («Данные и интеграции»).

## Принципы (предварительно)

- Все адаптеры приводят внешние данные к **единой внутренней модели** ([data-model.md](../02-architecture/data-model.md)).
- Уровни источника данных, от простого к сложному: Excel/CSV вручную → файл по расписанию → API облачной системы → локальный агент для 1С и офлайн-систем.
- Новая интеграция делается только под реальный спрос (подписавшиеся клиенты).
