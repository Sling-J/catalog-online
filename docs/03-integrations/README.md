# 03-integrations: интеграции с учётными системами

Ключевая зона риска и ценности. См. оценку в [../00-vision/idea-evaluation.md](../00-vision/idea-evaluation.md).

## Принципы (предварительно)

- Все адаптеры приводят внешние данные к **единой внутренней модели** (см. `02-architecture/data-model.md`).
- Уровни источника данных, от простого к сложному: Excel/CSV вручную → файл по расписанию → API облачной системы → локальный агент для 1С/офлайн-систем.
- Новая интеграция делается только под реальный спрос (подписавшиеся клиенты).
