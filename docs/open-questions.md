## Технические
- [x] Стек: `02-architecture/adr/0001-stack.md` (accepted). Хостинг — отдельно, см. ниже.
- [x] Линтер границ FSD: выбран `eslint-plugin-boundaries` (2026-11-01), настройка — `eslint.fsd.js`. Не проверяется импорт корня своего среза через `..` (через алиас запрещён) и правила структуры среза (модель только Effector, `api/` и т. п.) — остаются на ревью.
- [x] Контракт `POST /storefront/{поддомен}/cart/check`: в запросе только `variantId` и `quantity`, поэтому API не знает прежней цены и количества покупателя и не может сам вернуть `price_changed`, `quantity_reduced` и `previousPrice`. Предложение: либо убрать эти статусы и поле из контракта (оставить `ok`, `out_of_stock`, `unavailable`), либо добавить в запрос цену из корзины. Пока (T-107) фронт определяет «цена изменилась» и «количество уменьшено» сам, сравнивая ответ со снимком в корзине; работает при любом решении (2026-11-01). Решено основателем (2026-11-08): статусы `price_changed`, `quantity_reduced` и поле `previousPrice` убраны из контракта, остаются `ok` / `out_of_stock` / `unavailable` — `02-architecture/api.md`, «Уточнения контракта».
- [x] Контракт: 410 на `GET /storefront/{поддомен}` (T-110). Макет «Каталог скрыт» показывает логотип, WhatsApp, адрес и график, а в теле 410 был только Problem. Пока добавлено тело `StorefrontShopGone` (Problem + `shop` с этими полями) — нужно подтвердить; другой вариант: отдельный публичный запрос контактов. Статус ответа страницы при скрытом магазине сейчас 404 (роутер отдаёт 404 для not-found), для SEO нужен 410 — вернуться в T-111 (2026-11-01). T-111 (2026-11-02) это не меняла: такие страницы помечены `noindex` и отвечают 404, поисковики их не берут; 410 — когда витрина заработает с настоящим API (T-410, T-501). Решено основателем (2026-11-08): тело `StorefrontShopGone` подтверждено, отдельного запроса контактов нет — `api.md`, «Уточнения контракта». Статус 410 у страницы — в T-410 / T-501.
- [x] Контракт: `Import.rowCount` (T-309, 2026-11-07). Макет «Колонки» показывает «218 строк» до проверки, а число строк было только в `preview` (после сопоставления). Добавлено необязательное `rowCount` — API знает его после чтения файла. Нужно подтвердить; другой вариант — убрать число строк с шага «Колонки». Решено основателем (2026-11-08): `rowCount` подтверждён, API заполняет его после чтения файла — `api.md`, «Уточнения контракта».
