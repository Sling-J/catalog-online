| `multi-tenancy.md` | Изоляция магазинов, поддомены/домены | не начат |
| `sync-engine.md` | Как данные из интеграций попадают в каталог, конфликты, резервы | не начат |
| `nfr.md` | Нефункциональные требования: нагрузка, безопасность, доступность | не начат |
| [adr/](adr/README.md) | Журнал архитектурных решений | 0001 — стек, 0002 — FSD для фронтов, 0003 — формы на TanStack Form, 0004 — структура бэкенда (accepted) |
