Основная аудитория каталога сидит с телефона: mobile-first по умолчанию.

## Решения
- Инструмент: скилл Impeccable (см. [roles.md](../06-process/roles.md)).
- Где: холст-артефакт Design на claude.ai (решено 2026-10-31). Каждый экран — живой HTML-артборд, экраны лежат рядом. Figma не используем.
- Холст: https://claude.ai/artifact/Q9djVhqdPdb7CjTRvZcrnN (приватный; исходники артбордов — там же).
- Лендинг, 3 направления (2026-10-31): A «Сырмак» (войлочная аппликация, красный/индиго), B «Бирка» (магазинные бирки на рейле, зелёный/крафт/оранжевый), C «Шнур» (чёрный шёлк и золотой шнур, таблица собирается в каталог). Основателю не понравились.
- Ещё 8 стилистик (2026-10-31): D стекло и градиенты + история заказа, E бенто + градиенты, F тёмный техно-премиум с «живой» синхронизацией остатков, G яркий дружелюбный с объёмными предметами, H модный журнал, I тактильный (предметы на столе), J швейцарский минимализм (матрица наличия), K необрутализм. Основателю понравились D и G.
- Гибриды D+G (2026-10-31): из D — структура, шрифт Geologica, стекло; из G — парящие объёмные предметы, пухлые кнопки, дружелюбность; экран каталога в телефоне переделан. L «Стекло + пластилин», M «Аврора + стеклянные предметы», N «Сиреневый, два телефона» (интерактив: покупатель собирает заказ → он приходит в WhatsApp магазина → подтверждение списывает остаток; 2026-11-01 демо переделано под D14: магазин отвечает в чате, остатки не меняются).
- **Выбрано: N** (2026-10-31). Стиль: сиреневый фон, стекло, шрифт Geologica, пухлые кнопки с «подложкой», парящие пластилиновые предметы (пока CSS-заглушки, позже — настоящие 3D-иллюстрации).
- Дизайн-система (2026-10-31): метафора «Магазин в кармане»; стиль одинаково яркий на всех поверхностях (решение основателя), предметы не перекрывают данные; тёмной темы пока нет, цвета через токены. Лист на холсте — «Дизайн-система».
- Для контраста AA подправлены цвета мелкого текста относительно макета N: подписи #6B6694 (было #8A85AD), «мало» #A35A00 (было #C2700A), «есть» #157A52 (было #1E9E6A).
- Адаптив N (один файл, три ширины; на холсте артборды 1440 / 834 / 390):
  - ≤1000px: телефоны сужаются до 300px, стрелка между ними короче, предметы мельче.
  - ≤720px: в шапке только логотип и кнопка; главная кнопка на всю ширину; вместо двух телефонов — один с вкладками «Покупатель / Ваш WhatsApp»; после отправки заказа автоматически открывается «Ваш WhatsApp»; один из предметов скрыт, остальные уходят к краям; вертикальные отступы меньше.
- Уровни: лендинг сразу в полном качестве (выбор стиля) → вайрфреймы всех экранов витрины и админки + карта переходов → финальный вид в дизайн-системе.
- Стиль выбираем на 3 вариантах лендинга сервиса; витрина берёт его в более спокойном виде, админка — в режиме Operate.
