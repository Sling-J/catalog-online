# Админка магазина: экраны и поведение

Рабочее место владельца или продавца магазина. Основа: [requirements.md](../01-product/requirements.md) (FR-A1…A6, A8–A10), стиль — [DESIGN.md](../../DESIGN.md), режим Impeccable — Operate (задача важнее выразительности). Работают с телефона за прилавком и с компьютера при загрузке товаров (NFR-1).

Главная цель MVP — магазин сам создаёт сайт и загружает товары (D14). Заказы в админке не хранятся: покупатель отправляет корзину в WhatsApp, весь диалог идёт там.

Главные задачи, по частоте:
1. Завести товары: загрузить Excel или создать вручную — название, описание, размеры, количество, цена.
2. Добавить фото (с телефона, сразу после съёмки).
3. Обновлять остатки и цены: свежий Excel или правка одного товара.
4. Настроить магазин: описание, адрес, график, контакты.

## Навигация
- Разделы: **Товары**, **Импорт**, **Магазин** (настройки, публикация, статистика).
- Телефон: нижнее меню из 3 пунктов. Компьютер: колонка слева.
- Сверху всегда: название магазина, статус витрины («Опубликован» / «Черновик»), кнопка «Открыть витрину».

## Экраны

### 0. Вход, регистрация, мастер
- Регистрация: email, пароль → письмо с подтверждением.
- Мастер из 4 шагов, по экрану на шаг с прогрессом: название → адрес витрины (поддомен с проверкой «свободен / занят» на лету) → WhatsApp → логотип (можно пропустить).
- После мастера — главная с чек-листом.

### 1. Главная (пока магазин не опубликован)
Чек-лист готовности: «Магазин настроен», «Товары загружены», «У товаров есть фото (N без фото)», «Опубликовать». Каждый пункт ведёт на нужный экран. После публикации стартовым экраном становятся Товары.

### 2. Товары
- Список: фото, название, категория, цена (или «от»), суммарный остаток, метки «без фото», «скрыт», «нет в наличии».
- Поиск, фильтры (категория, без фото, скрытые, нет в наличии), сортировка; массовые действия: скрыть/показать, сменить категорию.
- Карточка товара: фото (загрузка нескольких, перетаскивание, первое — обложка), название, описание, категория, видимость; таблица вариантов: размер/атрибуты, цена, остаток, артикул, штрихкод; «+ Вариант». Поля, которые перезапишет импорт, помечены «из Excel».
- Ручное создание товара — полноценный путь наравне с импортом.
- Быстрый режим «Добавить фото»: очередь товаров без фото, по одному на экран — сфотографировал, «Дальше».

### 3. Импорт
- Шаг 1: загрузить файл (перетащить / выбрать), ссылка на шаблон.
- Шаг 2: сопоставление колонок (если заголовки не совпали), запоминается.
- Шаг 3: предпросмотр — будет создано / обновлено / обнулено, ошибки по строкам; переключатель «Артикулы, которых нет в файле: обнулить остаток / не трогать».
- Шаг 4: итог; история импортов.

### 4. Магазин
- Настройки: название, логотип, описание, WhatsApp, контакты, адрес и «как найти», график по дням, соцсети, показ отсутствующих товаров, показ остатка («есть / мало / нет» или число, порог «мало»), пароль.
- Категории и атрибуты: дерево категорий с порядком, атрибуты с порядком значений, выбор атрибутов для фильтров витрины.
- Публикация: адрес витрины, «Скопировать ссылку», «Опубликовать» / «Снять с публикации».
- Статистика: просмотры витрины и товаров, нажатия «Заказать через WhatsApp» за период.

## Пустые и служебные состояния
Нет товаров (→ импорт или создать вручную), импорт с ошибками, нет связи, загрузка.

## Адаптив
- Телефон: нижнее меню, списки в одну колонку, карточки на весь экран, главная кнопка закреплена внизу.
- Компьютер: меню слева; товары — таблица; карточка товара — фото слева, поля справа, таблица вариантов в полную ширину.

## Макеты
На холсте Design, раздел «На проверке — админка» (статичные экраны, фото — Unsplash):
- «Админка · телефон» — 5 экранов: главная до публикации с чек-листом, товары с баннером «37 без фото», карточка товара с пометками «из Excel», быстрый режим «Добавить фото», импорт — проверка.
- «Админка · компьютер 1440» — 3 экрана: таблица товаров с массовыми действиями, редактирование товара с таблицей вариантов, сопоставление колонок выгрузки из 1С.
- Меню сиреневое (снизу на телефоне, колонкой слева на компьютере), рабочая область на бумаге.
- Остальные экраны (утверждены 2026-10-31, A8):
  - «Админка · телефон — остальные экраны», 12: регистрация; мастер, шаг 1 (название, превью шапки), шаг 2 (адрес витрины с проверкой «свободен»), шаг 3 (WhatsApp с примером сообщения), шаг 4 (логотип: «Снять» / «Из галереи», можно пропустить); «Товаров пока нет» с выбором Excel / вручную; новый товар вручную (размеры чипами, цена по умолчанию одна, количество «− N +»); раздел «Магазин» (публикация и пункты настроек); «О магазине»; категории и свойства (порядок перетаскиванием, «в фильтрах»); «Наличие на витрине» (есть / мало / нет или число, порог «мало», показ закончившихся); статистика (просмотры, нажатия «Заказать», по дням, чаще смотрят).
  - «Админка · компьютер — регистрация и мастер; новый товар, о магазине», 8. Первый ряд — первый вход: регистрация (справа — три шага «загрузите → сфотографируйте → поделитесь»), мастер шаги 1–4 (название, адрес, WhatsApp, логотип) с живым превью витрины справа. Второй ряд: новый товар с таблицей размеров; «О магазине» в две колонки (сведения слева, график справа по ровной сетке: колонка дней фиксированной ширины, «открытие — закрытие», переключатель «рабочий»); то же с превью витрины, открытым по кнопке «Превью витрины» панелью поверх справа.
  - Правило (A7): превью витрины в настройках не занимает постоянную колонку — открывается по кнопке поверх содержимого справа.
- Вход, почта и пароль (утверждены основателем 2026-11-02, A11; T-302) — «Админка · телефон — вход, почта и пароль» (`AdminAuthPhone.dc.html`, 11 экранов: вход и ошибка входа, ошибки регистрации, «Забыли пароль», «Проверьте почту», новый пароль по ссылке, «Ссылка устарела» для пароля и для подтверждения почты, «Почта подтверждена», главная с неподтверждённой почтой, «Вход и пароль» в разделе «Магазин») и «Админка · компьютер 1440 — вход, почта и пароль» (`AdminAuthDesk.dc.html`, 9 экранов: то же без ошибок регистрации и главной). Генератор — `design/canvas/generators/gen-admin-auth.cjs`. Ошибки полей — по `DESIGN.md`: рамка coral-underside и подпись под полем.
- Мелочи, появившиеся в макетах (приняты основателем 2026-10-31): «Отправить себе тестовое сообщение» в мастере; артикул генерируется сам, если не указан; ссылка на 2ГИС находится по адресу; «Скопировать Пн на все будни» в графике; «Сохранить черновик» у нового товара (товар не виден на витрине).
