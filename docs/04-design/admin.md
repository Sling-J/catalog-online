# Админка магазина: экраны и поведение

Рабочее место владельца или продавца магазина. Основа: [requirements.md](../01-product/requirements.md) (FR-A1…A6, A8–A10), стиль — [DESIGN.md](../../DESIGN.md), режим Impeccable — Operate (задача важнее выразительности). Работают с телефона за прилавком и с компьютера при загрузке товаров (NFR-1).

Главная цель MVP — магазин сам создаёт сайт и загружает товары (D14). Заказы в админке не хранятся: покупатель отправляет корзину в WhatsApp, весь диалог идёт там.

Главные задачи, по частоте:
1. Завести товары: загрузить Excel или создать вручную — название, описание, размеры, количество, цена.
2. Добавить фото (с телефона, сразу после съёмки).
3. Обновлять остатки и цены: свежий Excel или правка одного товара.
4. Настроить магазин: описание, адрес, график, контакты.

## Экраны

### 0. Вход, регистрация, мастер
- Регистрация: email, пароль → письмо с подтверждением.
- Мастер из 4 шагов, по экрану на шаг с прогрессом: название → адрес витрины (поддомен с проверкой «свободен / занят» на лету) → WhatsApp → логотип (можно пропустить).
- После мастера — главная с чек-листом. На шаге «Логотип» одна кнопка: без логотипа «Пропустить», с ним «Готово →» (A33).

### 1. Главная
~~Чек-лист готовности: «Магазин настроен», «Товары загружены», «У товаров есть фото (N без фото)», «Опубликовать». Каждый пункт ведёт на нужный экран. После публикации стартовым экраном становятся Товары.~~ → A31, A33 (2026-11-08).

До запуска — чек-лист (A33): «Магазин создан ✓» (мастер засчитан), «Товары загружены», «У товаров есть фото», «Подтвердите почту» (пока не подтверждена), «Опубликуйте витрину»; отдельно необязательный «Расскажите о магазине» (адрес, график). «Опубликовать витрину» — со всеми причинами, если нельзя. После публикации — сводка (A31): ссылка на витрину («Скопировать», «Отправить ссылку в WhatsApp»), неделя в цифрах с переходом в статистику, «Нужно сделать» (подтвердить почту, без фото → быстрый режим, нет в наличии → вкладка, обновить остатки из Excel с датой последнего импорта). Главная — стартовый экран после входа в любом статусе.

### 2. Товары
- Список: фото, название, категория, цена (или «от»), суммарный остаток, метки «без фото», «скрыт», «нет в наличии».
- Поиск, фильтры (категория, без фото, скрытые, нет в наличии), сортировка; массовые действия: скрыть/показать, сменить категорию.
- Карточка товара: фото (загрузка нескольких, перетаскивание, первое — обложка), название, описание, категория, видимость; таблица вариантов: размер/атрибуты, цена, остаток, артикул, штрихкод; «+ Вариант». Поля, которые перезапишет импорт, помечены «из Excel».
- Ручное создание товара — полноценный путь наравне с импортом.
- Быстрый режим «Добавить фото»: очередь товаров без фото, по одному на экран — сфотографировал, «Дальше».

### 3. Импорт
- Шаг 1: загрузить файл (перетащить / выбрать), ссылка на шаблон.
- Шаг 2: сопоставление колонок (если заголовки не совпали), запоминается.
- Шаг 3: предпросмотр — будет создано / обновлено / обнулено, ошибки по строкам; переключатель «Артикулы, которых нет в файле: обнулить остаток / не трогать».
- Шаг 4: итог; история импортов.

### 4. Магазин
- С 2026-11-08 (A31): статистика — на главной (`/stats`), пароль и выход — в «Аккаунте» (`/account`), импорт — из «Товаров».
- Настройки: название, логотип, описание, WhatsApp, контакты, адрес и «как найти», график по дням, соцсети, показ отсутствующих товаров, показ остатка («есть / мало / нет» или число, порог «мало»), пароль.
- Категории и атрибуты: дерево категорий с порядком, атрибуты с порядком значений, выбор атрибутов для фильтров витрины.
- Публикация: адрес витрины, «Скопировать ссылку», «Опубликовать» / «Снять с публикации».
- Статистика: просмотры витрины и товаров, нажатия «Заказать через WhatsApp» за период.

## Пустые и служебные состояния
Нет товаров (→ импорт или создать вручную), импорт с ошибками, нет связи, загрузка.

## Адаптив
- Телефон: нижнее меню, списки в одну колонку, карточки на весь экран, главная кнопка закреплена внизу.
- Компьютер: меню слева; товары — таблица; карточка товара — фото слева, поля справа, таблица вариантов в полную ширину.
