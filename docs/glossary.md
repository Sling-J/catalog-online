# Глоссарий

| Термин | Значение |
|---|---|
| Магазин (tenant) | Клиент сервиса; у каждого свой изолированный каталог |
| Учётная система | ПО магазина с товарами и остатками: 1С, кассовые программы и др. |
| Товар | Карточка в каталоге (например, «Куртка зимняя») |
| Вариант / SKU | Конкретная позиция товара: размер, цвет; у неё есть остаток, цена, штрихкод |
| Остаток | Количество SKU в наличии |
| Резерв | Часть остатка, придержанная под заказ. В MVP резерва нет (D7, D14) |
| Адаптер | Модуль, переводящий данные конкретной учётной системы в единый формат |
| Канонический формат | Внутренняя единая модель товара/остатка |
| Синхронизация | Обновление каталога по данным учётной системы |
| Заявка / заказ | Корзина покупателя, отправленная готовым сообщением в WhatsApp магазина. В сервисе не хранится (D14) |
| Витрина | Публичный каталог магазина на поддомене `<поддомен>.<сервис>.kz` |
| Админка | Рабочее место магазина: товары, импорт, фото, настройки |
| Лендинг | Сайт сервиса на основном домене для владельцев магазинов |
| Импорт | Загрузка товаров и остатков из Excel/CSV с сопоставлением колонок и предпросмотром |
| Контракт API | `packages/contract/openapi.yaml` — описание всех запросов; из него генерируется код фронтов и бэка |
| Демо-магазин | «Айгерим Kids» — данные для моков, макетов и кнопки «Посмотреть пример» |
| Агент | Небольшая программа на компьютере магазина, выгружающая данные наружу |
| Нормализация | Приведение «грязной» номенклатуры к структуре товар → варианты |
