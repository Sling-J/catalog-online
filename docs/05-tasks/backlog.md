Проверено: SSR отдаёт данные из моков; service worker в браузере не проверен (встроенная панель их не поддерживает). Адрес фото в SSR-ответе строился от адреса запроса к API, а не страницы — исправлено в T-104 (моки отдают относительные адреса `/demo/…`, опция `assetBase`). — M · ADR
- [x] **T-102** Определение магазина по поддомену (изоморфная функция по заголовку Host вместо request middleware — см. примечание в ADR 0001); основной домен → лендинг; чужой адрес, служебный или неизвестный поддомен → «Магазин не найден» со статусом 404; в разработке — `<поддомен>.localhost:3000`, основной домен задаёт `VITE_ROOT_DOMAIN`. — M · ADR, FR-V1
- [x] **T-103** Шапка магазина и шторка «О магазине» (как найти, 2ГИС, график с «сегодня», контакты). Заодно подключён Lingui в `apps/web` (решение основателя 2026-11-01: строки через Lingui с первого экрана). «Открыто до…» считается по часовому поясу магазина; адрес 2ГИС — поиск по тексту адреса (координат у магазина нет). Выпадающая панель «О магазине» на компьютере не сделана: пока то же окно по центру — вернуться при адаптиве. — M · S «Каталог», «О магазине», FR-V9
- [x] **T-104** Каталог: категории чипами (подкатегории второй лентой), сетка 3 в ряд (5 на компьютере) с ценой и «мало», подгрузка курсором при прокрутке, сортировка, «N товаров» (по `facets.total`). Категория и сортировка — в адресе (`?category=…&sort=…`), данные предзагружает загрузчик маршрута. Моки теперь режут страницы по курсору, сортируют и считают `total` по выборке (тест `handlers.test.ts`). Проверено в настоящем Chrome (service worker моков работает): переход по чипу, сортировка, «Назад», подгрузка страниц (при размере страницы 6). Не проверена вторая лента — в демо-магазине нет подкатегорий (логика покрыта юнит-тестом). Нажатие на фото ведёт на будущий адрес карточки `/<slug>-<shortId>` обычной ссылкой — настоящая страница в T-106. — L · S7, FR-V2, FR-V5
- [x] **T-105** Поиск и фильтры: поиск по названию (пауза в наборе или Enter), шторка фильтров по `facets` (значения свойств, которые есть в выборке, и цена «от — до»), чипы выбранных с крестиком, кнопка со счётчиком, пустая выборка с «Сбросить поиск и фильтры»; всё в адресе (`q`, `values`, `priceMin`, `priceMax`), поиск и фильтры меняют запись истории, а не добавляют. Не сделан переключатель «Только в наличии» — в контракте для него нет параметра, вопрос в `open-questions.md`. Моки умеют `q`, `values`, цену и считают фасеты по выборке; исправлено совпадение id значений «рост 128» и «размер обуви 28» в демо-данных. Проверено в Chrome: поиск, значение, цена, чипы, сброс, ссылка с фильтрами; телефонная вёрстка. — L · FR-V3, FR-V4
- [x] **T-106** Карточка товара (телефон): галерея со свайпом и точками, выбор варианта по свойствам (закончившиеся зачёркнуты пунктиром и не выбираются, невозможные сочетания неактивны), наличие по настройке магазина, «Назад» с прежним выбором в каталоге, «Поделиться», «Можно примерить в магазине»; адрес `/<slug>-<shortId>`, при устаревшем slug 301 на актуальный, чужой адрес и основной домен — 404. Кнопка «В корзину» / «В корзине · открыть» работает на модели корзины `entities/cart` (Effector, хранение в `localStorage`, чтение после гидратации) — её заготовка сделана здесь, остальное в T-107. «В корзине · открыть» пока ничего не открывает (шторка — T-107). Карточка на компьютере пока та же колонка по центру (окно со стрелками — T-109); у несуществующего товара пока текст «Магазин не найден» (оформление состояний — T-110). Проверено в Chrome: переход из каталога, выбор размера, добавление, сохранение после перезагрузки, «Назад». — L · S6, FR-V6, DM3
- [x] **T-107** Корзина на Effector (модель и хранение на устройстве — с T-106): плавающая плашка «N товара в корзине · сумма → В корзину» в каталоге (на карточке её нет); шторка корзины (окно по центру на компьютере) — строки с миниатюрой, названием, вариантом, ценой, количеством «− N +» (не больше остатка, если он известен), «Убрать», комментарий для магазина, итог; перепроверка `cart/check` при открытии: общая плашка «магазин кое-что обновил» и плашки у строк (цена изменилась, количество уменьшено до остатка, закончился, недоступен — такие строки серые и в сумму не входят); без связи показывается сохранённая корзина с пояснением; шторка открывается и из каталога, и с карточки товара (одна на приложение, в корне). «Цена изменилась» и «количество уменьшено» фронт определяет сам, сравнивая ответ со снимком: API не знает прежней цены — вопрос в `open-questions.md`. Моки ограничивают количество у «мало» двумя штуками. Кнопки «Заказать через WhatsApp» пока нет — T-108. Проверено в Chrome: плашка, открытие с каталога и карточки, все четыре плашки изменений, «Убрать», количество, комментарий, сохранение; состояние без связи — во встроенном браузере. — L · FR-V7, S10
- [x] **T-108** «Заказать через WhatsApp»: мятная кнопка в шторке корзины — обычная ссылка `wa.me/<номер>?text=…` (браузер не блокирует, на телефоне сразу открывается приложение); текст по FR-V8 («Здравствуйте! - [x] **T-109** Компьютер (от 1024 px): шапка в одну строку — магазин (адрес сокращается, статус «Открыто до…» нет), поиск с кнопкой фильтров по центру, WhatsApp, кнопка корзины с суммой; категории под ней; сетка 5 колонок (была с T-104); «О магазине» и корзина — выпадающие панели 400 px под шапкой слева и справа; товар — окно 1040×720 поверх каталога: фото слева, информация справа, крестик, Esc и щелчок по затемнению закрывают, стрелки на экране и клавиши ← → листают соседние товары каталога (с тем же выбором категории и фильтров), страница под окном не прокручивается.
