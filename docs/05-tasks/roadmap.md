# Дорожная карта MVP

Порядок — как в [workflow.md](../06-process/workflow.md): фундамент → фронты на моках по контракту → API → связка и e2e → деплой → пилот. Первым делаем `web` (витрина и лендинг). Задачи по эпикам — в [backlog.md](backlog.md).

Размеры задач: **S** — до полудня, **M** — день-два, **L** — несколько дней (с ИИ, на одного разработчика). Сроков в датах не ставим, пока не пройдём первые эпики и не увидим реальную скорость.

| # | Эпик | Что получаем в конце | Зависит от |
|---|---|---|---|
| E0 | Фундамент | Монорепо, линтеры, тесты, CI, генерация кода из контракта, моки MSW, токены дизайн-системы в `packages/ui`, Docker для разработки | — |
| E1 | Витрина (`web`, на моках) | Рабочая витрина V6 на телефоне и компьютере: каталог, фильтры, карточка, корзина, WhatsApp, состояния, SEO и превью ссылок | E0 |
| E2 | Лендинг (`web`) | Лендинг N в трёх ширинах с живым демо, ведёт в регистрацию и на демо-магазин | E0 (компоненты из E1) |
| E3 | Админка (`admin`, на моках) | Все утверждённые экраны: вход и мастер, товары, редактор, фото, импорт, категории, настройки, статистика, превью витрины | E0 |
| E4 | API (`api`) | NestJS + PostgreSQL по контракту: вход, магазин, товары, фото, импорт, витрина, статистика, суперадминка; фоновые задачи | E0 |
| E5 | Связка и сквозные тесты | Фронты работают с настоящим API, Playwright-сценарии главных путей, демо-магазин | E1–E4 |
| E6 | Деплой и эксплуатация | ADR по хостингу, сервер, HTTPS для поддоменов, письма, бэкапы, мониторинг | E5, ответ по закону о данных |
| E7 | Пилот | 2–5 магазинов загрузили каталоги и пользуются (критерии в `mvp-scope.md`) | E6 |

E3 и E4 можно вести параллельно после E1: контракт общий, моки готовы с E0.

## Вехи
1. **Витрина на моках** (E0 + E1) — можно показать магазинам ссылку и собрать отзывы о витрине до готового бэка.
2. **Всё на моках** (+ E2, E3) — полный продукт кликается без сервера.
3. **Работает по-настоящему** (+ E4, E5) — локально весь путь: регистрация → импорт → витрина → WhatsApp.
4. **В интернете** (E6) — первые магазины на поддоменах.
5. **Пилот** (E7).
